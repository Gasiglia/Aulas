Introdução
Este projeto implementa um carousel de imagens que exibe três imagens por vez, com uma imagem fixa ao lado. O usuário pode navegar pelas imagens usando botões de próximo e anterior. Além disso, quando o usuário clica em uma imagem do carousel, ela substitui a imagem fixa ao lado e registra essa escolha na sessão.

Estrutura do Código
HTML
O código HTML contém uma estrutura de container com uma imagem fixa e um carousel deslizante.

CSS
As imagens e os elementos do carousel são estilizados para garantir uma boa apresentação visual.

JavaScript
O JavaScript controla a movimentação das imagens dentro do carousel, garantindo a transição entre elas. Além disso, ele permite que, ao clicar em uma imagem, ela substitua a imagem fixa e registre a escolha na sessão do usuário.

Classes e Elementos
.container - Contém a imagem fixa e o carousel.
.fixed-image - Exibe a imagem fixa ao lado do carousel.
.carousel - Container do carousel.
.carousel-inner - Armazena todas as imagens do carousel.
.grid-item - Cada imagem dentro do carousel.
.prev e .next - Botões de navegação do carousel.
Funcionamento do Carousel
O carousel exibe três imagens por vez e permite que o usuário avance ou retroceda no conjunto de imagens, garantindo que a navegação ocorra de maneira fluida. Quando o usuário clica em uma das imagens do carousel, a imagem fixa ao lado é substituída pela imagem escolhida e a escolha é registrada na sessão do navegador.

Execução
Para rodar o projeto, basta abrir o arquivo HTML no navegador. O JavaScript será carregado automaticamente e permitirá a navegação no carousel. Quando o usuário clicar em uma imagem do carousel, a imagem fixa será atualizada e gravada na sessão.
